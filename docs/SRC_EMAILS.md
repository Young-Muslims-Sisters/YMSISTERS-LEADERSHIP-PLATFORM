# SRC notification emails: what we still need

**Status:** off. The form, directory and IT dashboard work without this. Submissions are saved and marked "No route" in the IT dashboard, and nobody is emailed.

**How it will work:** when someone submits the form, one short email goes to the SRC group for their subregion. It is only an update, so there is nothing to approve. It includes their name, subregion and role(s), and who to contact if something is wrong. It never includes birthday, ethnicity or other private answers.
